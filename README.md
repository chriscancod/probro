# ProBro

A calm, focus-first desktop browser (Electron) built for easily-distracted brains.

- **Islands** – School, Work, Break. Each has its own tabs, tasks and allowed sites.
- **Focus with an ease-in** – start with a gentle 10 minutes, then choose to keep going (+15) or break. Breaks auto-switch to the Break island.
- **Soft or hard blocking, per island** – wander to a site outside the island and get a 10-second pause (then your choice), or a hard block. Overrides are logged. Strictness can't be loosened mid-session.
- **Tasks** – pick one current task; it sits under the timer.
- **Brain dump** – park stray thoughts without leaving the page (`Ctrl/⌘+J`).
- **Today** – focus minutes, pauses, overrides.
- Local-only storage via `store.js` (one place to add sync later).

Shortcuts: `Ctrl/⌘+T` new tab · `W` close · `L` address bar · `J` brain dump · `1/2/3` islands.

```
npm install
npm start
```
